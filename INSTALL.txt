Instagram Embed Playback Controls
Chrome / Microsoft Edge - Windows, macOS and Linux

INSTALL ON EACH PC
1. Download and extract the release ZIP to a folder you will keep.
2. Open chrome://extensions in Chrome, or edge://extensions in Edge.
3. Enable Developer mode and choose Load unpacked.
4. Select the extracted instagram-embed-controls folder containing manifest.json.
5. Reload the page containing the Instagram embed. In Content Studio, open a
   reference and select Instagram embed (the Instagram icon by Live player).

Use the same ZIP on every PC. Keep the extracted folder in place.

CONTROLS
Seek, play/pause, playback speed, back five seconds, mute and volume controls
are added inside Instagram embeds when the embedded video is available.
This companion can coexist with the original Video Control for Instagram.
The Content Studio Live player already has its own playback controls.
If Instagram cannot load a video, use Live player or open the original reel.

The extension does not grant access to any private website. Use the account
approved for your website. No API keys, passwords, local server or Python
installation are included or required for this extension.

REMOVE
Open your browser's Extensions page and select Remove for
Video Control for Instagram - Embed Support.
